# Plus wordmark font

Allura Regular, designed by Robert Leuschke, Copyright 2010 The Allura
Project Authors. Licensed under SIL Open Font License 1.1; see Allura-OFL.txt.
The original font and upstream font log are retained unmodified.

Font and license source:
https://github.com/googlefonts/allura/tree/38a78b41510a10b1129c50fa5177b642bd2b4a19
Font file: fonts/ttf/Allura-Regular.ttf
Font log: https://github.com/google/fonts/blob/main/ofl/allura/FONTLOG.txt

Bundled in Qt resources so the Plus label has consistent styling without
requiring a font installation on macOS or Windows. It is a complementary
script face, not a claim that it is the original Gyroflow lettering font.
